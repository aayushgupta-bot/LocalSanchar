# Local Sanchar 📺

> **Helping local businesses get seen, remembered, and chosen.**

A premium, conversion-focused web application for **Local Sanchar** — a hyperlocal digital screen advertising startup helping restaurants, gyms, salons, clinics, cafés, retail stores, coaching institutes, and local brands advertise across high-footfall commercial display networks.

---

## 🌟 Key Features

* **Live Digital Display Totem Simulator:** Interactive 4K commercial display mockups showcasing authentic ad creatives across 5+ business sectors.
* **10 Business Category Portfolios:** Tailored campaign solutions for *Restaurants, Gyms, Salons, Clinics, Cafés, Retail Stores, Coaching Institutes, Local Brands, Real Estate, and Events*.
* **Transparent Pricing Architecture:**
  * **STARTER:** ₹300 / Month (10-second spot, 10–12 hours daily screen time)
  * **PROFESSIONAL:** ₹500 / Month (Includes professional video editing & creative enhancement)
  * **GROWTH:** ₹2,000 / 3 Months (Up to 2-minute video, screen advertising + social re-sharing)
  * **PREMIUM:** ₹4,000 / 6 Months (Flagship campaign with priority support & periodic refreshes)
* **Lead Capture & WhatsApp Direct Routing:** Automatic pre-filled campaign enquiry generation connected to `+919026467041`.
* **Mobile-First Conversion UX:** Sticky bottom conversion actions, fast modals, and accordion FAQs.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Effects:** Canvas Confetti

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/aayushhpvt/LocalSanchar.git
cd LocalSanchar
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
